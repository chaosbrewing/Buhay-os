name: Responsive navigation
description: Approved phone and desktop navigation direction for the web planner.
---

Use five main phone destinations: Today, Planner, Capture, Review and You (founder decision D3, 2026-10-25; replaces the earlier Today, Plan, Inbox, Notes and More). Today opens directly; the other four open sheets. Keep grouped collapsible navigation on desktop, unchanged.

**Why:** The founder's HANAY continuation directive proposed this navigation, and the founder explicitly approved replacing the earlier phone tabs with it. The earlier crowded-navigation concern still applies: keep exactly five tabs.

**How to apply:** Planner holds Week, Calendar, Projects, Habits, Routines, Templates, plus Goals, Life Areas and Search when their Release 2 flags are on. Capture holds Inbox and Notes. Review holds Reviews and Timeline when enabled and says plainly when neither is switched on. You holds Settings and Versions (and later memory, connected accounts and privacy). Preserve direct routes and existing feature flags. This approval targets the responsive web app, not native development.
