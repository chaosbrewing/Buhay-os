name: Responsive navigation
description: Approved phone and desktop navigation direction for the web planner.
---

Use five main phone destinations: Today, Plan, Inbox, Notes and More. Use grouped collapsible navigation on desktop.

**Why:** The user found the navigation crowded and explicitly approved combining these two approaches.

**How to apply:** Keep planning views under Plan on phones and secondary modules under More. Preserve direct routes and existing feature flags. This approval targets the responsive web app, not unrelated native development.
