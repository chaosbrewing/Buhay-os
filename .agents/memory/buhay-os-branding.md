The product's public name is HANAY (formerly BUHAY.OS), styled "hanay." as a visual wordmark only. Tagline: "Make room for life." Design direction: ORIGIN Glass, with Daylight and Midnight themes (sage, forest green, pearl, celadon, muted gold). The wordmark assets are `attached_assets/hanay-wordmark-light.png` and `hanay-wordmark-dark.png`.

**Why:** The founder approved decisions HANAY-001 to HANAY-006 on 2026-11-21: adopt the name, adopt the wordmark, keep all features and internal modules (BAKAS, TUKLAS, UGNAY), adopt the ORIGIN Glass direction, preserve technical identifiers, and authorise the audit and specification. See `docs/HANAY_Brand_and_Migration_Specification_v0.1.md`.

**How to apply:** Write "HANAY" in anything a person reads. Never put the period of "hanay." into code or identifiers. Do not rename storage keys, the backup format `buhay-os-encrypted-backup` (it is bound into the encryption), the `.buhaybackup` extension, Google Calendar request keys, package names, URL schemes or deployment paths without a verified migration. `src/rebrand-compat.test.mjs` pins these. The repository rename is not authorised.
